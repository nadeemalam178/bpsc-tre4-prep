## 🅰️ Section 1: Hindi Grammar (Sandhi & Samas Explained in English)

### 1. Sandhi (Phonetic Conjunction Rules)
Sandhi refers to the transformation or euphonic change produced by the conjunction of two adjacent letters or phonemes.

#### (A) Svar Sandhi (Vowel Conjunction) — 5 Cardinal Types:
1. **Dirgha Sandhi (Vowel Lengthening):**
   - $a / \bar{a} + a / \bar{a} \rightarrow \bar{a}$ (e.g., Deva + Alaya = **Devalaya**, Vidya + Arthi = **Vidyarthi**)
   - $i / \bar{\imath} + i / \bar{\imath} \rightarrow \bar{\imath}$ (e.g., Kapi + Isha = **Kapisha**, Giri + Indra = **Girindra**)
   - $u / \bar{u} + u / \bar{u} \rightarrow \bar{u}$ (e.g., Bhanu + Udaya = **Bhanudaya**, Vadhu + Utsava = **Vadhutsava**)
2. **Guna Sandhi:**
   - $a / \bar{a} + i / \bar{\imath} \rightarrow e$ (e.g., Nara + Indra = **Narendra**, Maha + Isha = **Mahesha**)
   - $a / \bar{a} + u / \bar{u} \rightarrow o$ (e.g., Surya + Udaya = **Suryodaya**, Maha + Utsava = **Mahotsava**)
   - $a / \bar{a} + \underset{\cdot}{r} \rightarrow ar$ (e.g., Deva + Rishi = **Devarshi**, Maha + Rishi = **Maharshi**)
3. **Vriddhi Sandhi (Vowel Augmentation):**
   - $a / \bar{a} + e / ai \rightarrow ai$ (e.g., Eka + Eka = **Ekaika**, Mata + Aikya = **Mataikya**)
   - $a / \bar{a} + o / au \rightarrow au$ (e.g., Vana + Aushadhi = **Vanaushadhi**, Maha + Audarya = **Mahaudarya**)
4. **Yan Sandhi (Semi-vowel Conversion):**
   - $i / \bar{\imath} + \text{Dissimilar Vowel} \rightarrow y$ (e.g., Yadi + Api = **Yadyapi**, Iti + Aadi = **Ityaadi**)
   - $u / \bar{u} + \text{Dissimilar Vowel} \rightarrow v$ (e.g., Su + Aagata = **Swaagata**, Anu + Aya = **Anwaya**)
   - $\underset{\cdot}{r} + \text{Dissimilar Vowel} \rightarrow r$ (e.g., Pitri + Aagya = **Pitraagya**)
5. **Ayadi Sandhi:**
   - $e + \text{Vowel} \rightarrow ay$ (e.g., Ne + Ana = **Nayana**)
   - $ai + \text{Vowel} \rightarrow \bar{a}y$ (e.g., Gai + Aka = **Gaayaka**)
   - $o + \text{Vowel} \rightarrow av$ (e.g., Po + Ana = **Pavana**)
   - $au + \text{Vowel} \rightarrow \bar{a}v$ (e.g., Pau + Aka = **Paavaka**)

#### (B) High-Yield Consonant & Visarga Sandhi:
- **Ujjwal:** Ut + Jwal (Rule: Dental 't' assimilates before palatal 'j' $\rightarrow$ 'jj'). Note: Both letters are half-consonants (उज्ज्वल).
- **Sajjan:** Sat + Jana (सज्जन)
- **Manorath:** Manah + Ratha (मनः + रथ $\rightarrow$ Visarga changes to 'o')
- **Nishkapat:** Nih + Kapata (निः + कपट $\rightarrow$ Visarga changes to retroflex 'sh' ष)

### 2. Samas (Compound Words) — Core Principles

| Compound Name | Dominant Constituent | Identification Anchor | Authentic Examples |
|:---|:---|:---|:---|
| **Avyayibhav** | First word dominant (Indeclinable prefix) | Starts with Yatha, Prati, Be, Ba, Bhar, Anu | Yathashakti, Pratidin, Aajanam, Bharpet |
| **Tatpurush** | Second word dominant | Elision of case postpositions (Karak Vibhakti) | Rajputra (King's son), Rogamukta (Free from disease) |
| **Karmadharay** | Second word dominant | Adjective-Noun or Comparison relation | Neelkamal (Blue lotus), Charan-kamal |
| **Dvigu** | First word is a cardinal numeral | Signifies a collective set or group | Chauraha (Four roads), Triphala, Navaratna |
| **Dvandva** | Both words equally dominant | Connected by 'and' or hyphenated opposites | Mata-Pita (Mother and Father), Sukh-Dukh |
| **Bahuvrihi** | Neither word dominant (Third meaning) | Points to a distinctive external deity/entity | Dashanana (Ravana), Lambodara (Ganesha), Chakrapani (Vishnu) |

## 🅱️ Section 2: General English (Core Competitive Grammar)

### 1. Subject-Verb Agreement: Rule of Proximity
When two subjects are joined by correlative conjunctions:
- **Neither...nor**
- **Either...or**
- **Not only...but also**

**The finite verb agrees strictly in number and person with the SUBJECT CLOSEST TO IT.**
- Correct: "Neither the principal nor the **teachers were** present."
- Correct: "Neither the teachers nor the **principal was** present."

### 2. Phonetic Article Rules
- Use **'a'** before words starting with a consonant phonetic sound, including vowel letters pronounced with consonant semi-vowel glides:
  - *a European, a university, a uniform, a union, a one-rupee note*.
- Use **'an'** before words starting with a vowel phonetic sound, including silent 'h':
  - *an honest man, an hour, an heir, an honor, an MP, an MLA*.
