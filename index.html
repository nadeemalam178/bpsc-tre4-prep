गणित सूत्र संकलन

• a × b = HCF × LCM • 1/α + 1/β = -b/c (सीधा शॉर्टकट) • ax² + bx + c = 0 में यदि a, b, c > 0 हों, तो दोनों शून्यक ऋणात्मक होंगे • दशमलव सांत स्थान = max(n, m) in 2^n · 5^m • रैखिक समीकरण: कोई हल नहीं ⇔ a1/a2 = b1/b2 ≠ c1/c2 • अपरिमित अनेक हल ⇔ a1/a2 = b1/b2 = c1/c2 • समतल दर्पण प्रतिबिंब संख्या = (360° / θ) - 1
